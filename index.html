        02 · Documentation gap

        GDPR checklist for candidate data migration

        Ashby's Greenhouse API migration does not carry over candidate consent dates or data retention dates. For an EU customer, that means candidates can arrive in Ashby with no retention clock. This checklist closes that gap and sets up Ashby's own compliance tools before go-live.

        0 / 0

        This is an implementation checklist, not legal advice. The customer's DPO or legal team decides the lawful basis and retention periods; the implementation makes sure Ashby enforces what they decide.
